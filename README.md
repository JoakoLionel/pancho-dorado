# Pancho Dorado

Página web de un local de panchos. Muestra el menú con fotos y precios, y toma el pedido con un
bot (Panchi) que entiende frases como "quiero 2 clásicos y una coca para retirar", calcula el
total según las cantidades y confirma la orden para retiro o delivery.

Ver la página: https://joakolionel.github.io/pancho-dorado/
